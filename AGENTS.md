# Agents

## Commit Practices

- **Commit early and often.** Don't let work accumulate in the working copy. Commit regularly as you make progress.
- **Use Conventional Commits.** All commit messages must follow the [Conventional Commits](https://www.conventionalcommits.org/) format (e.g. `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`).
- **Break changes into separate commits.** If the working copy contains multiple logical changes, split them into individual commits. Each commit should be a self-contained, coherent unit of work.
